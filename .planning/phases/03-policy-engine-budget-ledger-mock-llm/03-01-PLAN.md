<objective>
Extend the Policy schema with the two fields Phase 3 needs (`max_steps`, `model_prices`) and build `engine.py`: a pure `decide()` function that turns a policy, a request and the current budget state into a structured `Decision`, with no I/O, no clock and no framework import anywhere in the module.

Purpose: POLICY-03 requires enforcement logic that is provably pure and testable in isolation — the schema change is a prerequisite (the pricing table and step ceiling `decide()` reasons about must exist on `Policy` first), and 03-RESEARCH.md identified that this exact change breaks five existing Phase 2 test sites if those sites are not updated in the same commit (Pitfall 6). This plan is also where BUDGET-05's two hardest correctness properties live: `Decimal.quantize` rounds a real per-token cost to zero under the default rounding mode, and `Usage` must make "no reading" and "a zero reading" impossible to confuse.

Output: `src/eacp/policy.py` (extended), `src/eacp/engine.py` (new), `src/eacp/errors.py` (extended), `tests/conftest.py` (extended), `tests/test_policy.py` (extended), `tests/test_engine.py` (new).

Scope boundary: this plan does not touch SQLite, the clock, or any cross-process concern — that is Plan 03-02's ledger, which calls `decide()` from inside its own transaction. This plan does not build the mock LLM (Plan 03-03). `PolicyDenied` is defined here but first raised in Plan 03-02.
</objective>

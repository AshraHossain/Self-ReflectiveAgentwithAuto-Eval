## Accomplishments

- `pyproject.toml` declares a core dependency set containing **zero** agent frameworks (`pydantic`, `pyyaml`, `typer`, `opentelemetry-api`, `opentelemetry-sdk`) and exactly four extras: `langgraph`, `crewai`, `ag2`, `all`. This is the only place PACKAGE-01 can be made true, and it is now fixed before nine further phases add dependencies on top of it.
- `uv.lock` committed: **172 packages, 2016 `sha256` hashes, `revision = 3`**, generated by uv **0.12.19** — the same version plan 01-03 pins into CI, so `uv lock --check` cannot fail spuriously on a revision mismatch.
- Proven, not assumed: `uv sync --locked --no-default-groups` realizes a **17-package** environment in which `importlib.util.find_spec` returns `None` for `langgraph`, `crewai`, `ag2`, and `langchain_core`, while `import eacp` succeeds and reports `0.1.0`. This host has a *global* `crewai 1.9.3` installed, so the venv-scoped check is also a real leakage test, and it passed.
- `eacp.__version__` and `importlib.metadata.version("eacp")` both report `0.1.0` from the single `__about__.py` assignment — the two cannot drift.
- README carries the five-row platform matrix and states the mechanism of the CrewAI gap (`crewai>=1.15` → `lancedb>=0.29.2,<0.30.1`, which publishes no `macosx_*_x86_64` wheel and no sdist), not just the symptom.

## Decisions Made

- **Reused the prior interrupted attempt's `pyproject.toml`, `.gitignore`, `.python-version` after verifying them against Task 1's acceptance criteria** rather than rewriting them. 19 of 20 checks passed as found; the one failure was fixed (see Deviations).
- **Upgraded uv in place via `pip3 install --upgrade 'uv==0.12.19'`** on the framework Python. `uv self update` refused (pip-install method). A standalone uv 0.12.19 already existed at `~/.local/bin/uv`, but `PATH` put the stale pip copy (`/Library/Frameworks/Python.framework/Versions/3.13/bin/uv`, 0.9.30) first — so bare `uv` was 0.9.30 and would have silently generated the lockfile with the wrong version. Upgrading in place was chosen over `pip uninstall uv` because it is additive, touches exactly one dependency-free package, and leaves both copies consistent at 0.12.19.
- **Did not add `examples/`, `docs/`, `benchmarks/` directories.** D-03's placement decision is recorded here and in `.gitignore`'s deliberate silence; git cannot commit an empty directory and those paths arrive with content in Phases 8-10.
